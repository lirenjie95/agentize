# 教程目录

本目录包含学习 Agentize 的分步教程。

## 学习路径

在 15-25 分钟内完成所有教程（每个 3-5 分钟）：

1. `00-cli-quickstart.md` - 从配置到实现的 CLI 工作流（推荐）
2. `00a-claude-ui-setup.md` - 面向斜杠命令的 Claude UI 配置
3. `01-ultra-planner.md` - 使用 `lol plan --editor` 进行 CLI 规划
4. `02-issue-to-impl.md` - 实现；与 01 一起构成端到端流程
5. `03-vscode-planning.md` - 从 VS Code Activity Bar 进行规划和实现
6. `03-advanced-usage.md` - 使用克隆或 worktree 的并行开发工作流
7. `04a-project.md` - 使用 PAT 配置项目看板自动化

## 教程格式

每个教程包括：
- 预估阅读时间（3-5 分钟）
- 带代码示例的分步说明
- 清晰的学习目标
- 相关文档的链接

## 开始使用

CLI 新用户应从 `00-cli-quickstart.md` 开始，并按顺序完成整个系列。
Claude UI 用户可以改为从 `00a-claude-ui-setup.md` 开始。
